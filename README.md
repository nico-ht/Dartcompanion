# Darts Scorer für Android

Die Android-App ist vollständig kostenlos. Alle Funktionen sind ohne Abonnement und ohne In-App-Käufe verfügbar.

## Download

[Neueste APK herunterladen](https://github.com/nico-ht/Dartcompanion/releases/latest)

Die APK auf dem Android-Gerät öffnen und die Installation bestätigen. Falls Android nachfragt, die Installation für diese Downloadquelle erlauben.

## Updates

Ab Version 1.1.27 prüft die App automatisch auf neue Versionen. Unter **Einstellungen → Nach Updates suchen** ist auch eine manuelle Prüfung möglich.

Updates über die vorhandene App installieren. **Nicht vorher deinstallieren**, damit Spieler, Matches, Trainingsdaten und Einstellungen erhalten bleiben.

## Inhalt dieses Repositorys

Hier werden ausschließlich fertige Android-APKs, Update-Manifeste und Hinweise zur Installation veröffentlicht. Der App-Quellcode bleibt privat. Die von GitHub automatisch angebotenen „Source code“-Archive enthalten nur diese Download-Dokumentation, keinen App-Quellcode.

Die iOS-App behält ihr bestehendes Abonnement-Modell.
